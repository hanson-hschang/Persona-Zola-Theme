<p><code>Persona</code> uses Pandoc to turn citation keys into linked, formatted citations and a bibliography during the build. This guide covers setup, authoring, and previewing a citation-enabled post <span class="citation" data-cites="zolathemes">(<a href="#ref-zolathemes" role="doc-biblioref">Zola themes</a>)</span>. The workflow suits technical, research, and reference-heavy writing.</p>
<h2 id="requirements-and-setup">Requirements and setup</h2>
<p>Install Pandoc and watchexec:</p>
<div class="sourceCode" id="cb1"><pre class="sourceCode bash"><code class="sourceCode bash"><span id="cb1-1"><a href="#cb1-1" aria-hidden="true" tabindex="-1"></a><span class="co"># macOS</span></span>
<span id="cb1-2"><a href="#cb1-2" aria-hidden="true" tabindex="-1"></a><span class="ex">brew</span> install pandoc watchexec</span>
<span id="cb1-3"><a href="#cb1-3" aria-hidden="true" tabindex="-1"></a></span>
<span id="cb1-4"><a href="#cb1-4" aria-hidden="true" tabindex="-1"></a><span class="co"># Ubuntu / Debian</span></span>
<span id="cb1-5"><a href="#cb1-5" aria-hidden="true" tabindex="-1"></a><span class="fu">sudo</span> apt install pandoc</span>
<span id="cb1-6"><a href="#cb1-6" aria-hidden="true" tabindex="-1"></a><span class="ex">cargo</span> install watchexec-cli</span></code></pre></div>
<p>From your site root, copy the build scripts and Makefile from the theme:</p>
<div class="sourceCode" id="cb2"><pre class="sourceCode bash"><code class="sourceCode bash"><span id="cb2-1"><a href="#cb2-1" aria-hidden="true" tabindex="-1"></a><span class="fu">cp</span> <span class="at">-r</span> themes/persona/<span class="dt">{scripts</span><span class="op">,</span><span class="dt">Makefile}</span> .</span></code></pre></div>

<h2 id="write-a-post">Write a post</h2>
<p>Keep the source, bibliography, and generated Markdown in the same folder:</p>
<ul>
<li><code>index.src.md</code> is the authoring source.</li>
<li><code>references.bib</code> stores the BibTeX entries.</li>
<li><code>index.md</code> is generated by Pandoc; edit the source instead.</li>
</ul>
<h2 id="write-citations-in-.src.md">Write citations in <code>.src.md</code></h2>
<p>Use <a href="https://pandoc.org/demo/example33/8.20-citation-syntax.html">Pandoc citation syntax</a> in Markdown:</p>
<div class="sourceCode" id="cb4"><pre class="sourceCode markdown"><code class="sourceCode markdown"><span id="cb4-1"><a href="#cb4-1" aria-hidden="true" tabindex="-1"></a>Climate change is accelerating<span class="co">[</span><span class="ot">@ipcc2021</span><span class="co">]</span>.</span>
<span id="cb4-2"><a href="#cb4-2" aria-hidden="true" tabindex="-1"></a>Multiple studies confirm this<span class="co">[</span><span class="ot">@ipcc2021; @nasa2023</span><span class="co">]</span>.</span></code></pre></div>
<p>Add citation settings to the post’s <code>[extra]</code> front matter:</p>
<ul>
<li><code>citation_style = "apa"</code></li>
<li><code>bibliography = "references.bib"</code></li>
</ul>
<p>Set the citation style once for the site if you want it to apply to posts by default.</p>
<h2 id="mathematics-and-latex-macros">Mathematics and LaTeX macros</h2>
<p>Define reusable KaTeX macros in <code>[extra.tex.macros]</code>. TOML literal strings preserve backslashes:</p>
<div class="sourceCode" id="cb5"><pre class="sourceCode toml"><code class="sourceCode toml"><span id="cb5-1"><a href="#cb5-1" aria-hidden="true" tabindex="-1"></a><span class="kw">[extra.tex.macros]</span></span>
<span id="cb5-2"><a href="#cb5-2" aria-hidden="true" tabindex="-1"></a><span class="dt">&#39;\Real&#39;</span> <span class="op">=</span> <span class="st">&#39;</span><span class="vs">\mathbb{R}^{#1}</span><span class="st">&#39;</span></span>
<span id="cb5-3"><a href="#cb5-3" aria-hidden="true" tabindex="-1"></a><span class="dt">&#39;\norm&#39;</span> <span class="op">=</span> <span class="st">&#39;</span><span class="vs">\left\lVert #1 \right\rVert</span><span class="st">&#39;</span></span></code></pre></div>
<p>For a vector <span class="math inline">\(x \in \Real{n}\)</span>, the Euclidean norm is</p>
<p><span class="math display">\[
\norm{x}_2 = \sqrt{\sum_{i=1}^{n} x_i^2}.
\]</span></p>
<p>Write inline mathematics between <code>$</code> delimiters and display mathematics between <code>$$</code> delimiters. Pandoc preserves the expressions for KaTeX, including these page-specific macros. Citation references and mathematics can appear together in the same article <span class="citation" data-cites="zolathemes">(<a href="#ref-zolathemes" role="doc-biblioref">Zola themes</a>)</span>.</p>
<h2 id="build-and-preview">Build and preview</h2>
<p>Use the copied Makefile to build or preview your site:</p>
<div class="sourceCode" id="cb6"><pre class="sourceCode bash"><code class="sourceCode bash"><span id="cb6-1"><a href="#cb6-1" aria-hidden="true" tabindex="-1"></a><span class="fu">make</span> build</span>
<span id="cb6-2"><a href="#cb6-2" aria-hidden="true" tabindex="-1"></a><span class="fu">make</span> serve</span></code></pre></div>
<p><code>make build</code> converts changed <code>.src.md</code> files into <code>.md</code> files; run <code>zola build</code> to generate the site. <code>make serve</code> watches the sources and dependencies, rebuilds when needed, and runs <code>zola serve</code>. The incremental build checks the scripts, configuration, bibliography, and CSL files. Generated <code>.md</code> files do not trigger another rebuild.</p>
<p>To rerun preprocessing after changing the pipeline, run <code>bash scripts/build.sh</code> from your site root. If you use the scripts directly from the installed theme, run <code>bash themes/persona/scripts/build.sh</code> from the site root.</p>
<h2 id="citation-style-resolution-order">Citation style resolution order</h2>
<p>The preprocessor selects a CSL style in this order:</p>
<ol type="1">
<li>The post’s <code>[extra].citation_style</code>, resolved from <code>citation-style/&lt;name&gt;.csl</code>.</li>
<li>A <code>style.csl</code> beside the <code>.src.md</code> file.</li>
<li>Site <code>config.toml</code>: <code>[extra].citation_style</code> or <code>[extra.persona].citation_style</code>.</li>
<li>Theme <code>themes/persona/theme.toml</code> <code>[extra].citation_style</code>, or <code>themes/persona/config.toml</code> <code>[extra.persona].citation_style</code>.</li>
</ol>
<p>Persona includes the <code>ieee</code> and <code>apa</code> styles. Add custom CSL files to your site’s <code>citation-style/</code> directory or place a <code>style.csl</code> beside a post source. If a named post style cannot be found, the preprocessor warns and falls back to the configured default. The build script requires a site or theme default style.</p>
<h2 id="output-and-styling">Output and styling</h2>
<p>Pandoc emits HTML citations and a bibliography with stable classes that the theme styles:</p>
<ul>
<li><code>.citation</code></li>
<li><code>.references</code></li>
<li><code>.csl-entry</code></li>
<li><code>.csl-left-margin</code></li>
<li><code>.csl-right-inline</code></li>
</ul>
<p>Inline citations link to their bibliography entries. The bibliography appears inside the <code>references</code> container under <strong>Bibliography</strong>, after the optional <strong>Citation</strong> section. That section displays the post’s <code>[extra.post].bibtex</code>; the bibliography lists works cited in the text. This guide includes a sample BibTeX record to demonstrate both.</p>
<p>For the complete example, see this guide’s <a href="https://github.com/hanson-hschang/Persona-Zola-Theme/tree/main/content/maps/private-soul/citation-pipeline-guide/">source directory</a>.</p>
